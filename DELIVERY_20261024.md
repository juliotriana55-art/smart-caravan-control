# Smart Caravan Control 5.2 — integrated staging update

Same private HTTPS application: https://smart-caravan-staging-oct22.ivorysiren17.chatgpt.site
Work branch: staging/final-integration-20261022. Production main and worker.js remain unchanged.

## Shipped software changes
- Diagnostics-first read-only connection. An installation with only tanks/inverter is no longer rejected by the legacy battery-centric telemetry route. The legacy summary is used only when diagnostics is unsupported (404/405).
- Shared telemetry parser for browser and tests. Scalar/tank zero values remain valid; empty/invalid/unknown/future readings stay missing. Source age is tracked per field; unrelated diagnostic records do not make old battery readings fresh. A newer missing tank reading suppresses an older zero.
- Dashboard and Jay use the same readings. Battery power is explicitly calculated as V × A only when the voltage/current timestamps are within 60 seconds. AC and DC queries are handled separately.
- HTTP/configuration failures show DATA UNAVAILABLE, failed network requests show OFFLINE, old valid samples show STALE DATA. ONLINE is recent recognized VRM telemetry, not an independent Cerbo network heartbeat.
- New connection requests cancel/supersede old requests; late responses cannot overwrite new settings. The last snapshot is retained during outages, never claimed as live before reconnection.
- Canonical saved settings take precedence over obsolete versions. Corrupt stored JSON/task entries no longer prevent startup. Profile changes autosave on field change; blank equipment counts remain different from explicit zero.
- Digital Twin now has native local photo upload/gallery and manually placed component markers linked to Jay. The separate simulated Pilot 5 iframe was removed from the integrated UI. Existing standalone prototypes and the embedded exterior 3D prototype are preserved. The generic geometry remains illustrative, not a scan.
- Local PDF manual upload/download/delete with MIME, signature and size checks. Jay does not automatically read PDF contents. Existing notes/links remain.
- Assistant name and speech language are in Settings. Voice preferences, history and response modes persist. Speech callback isolation prevents old replies changing the state of newer ones. A visible text/replay fallback appears if Voice Only playback fails. Safari continuous wake recognition directs users to Push to Talk.
- Offline shell includes all new scripts and skips API/authenticated requests. New shell activates only after required files cache successfully.
- Reproducible packaging command: `node tools/package-staging.mjs --output /absolute/site/worker/index.js`. Deployment is separate; this command does not deploy or touch the production Worker.
